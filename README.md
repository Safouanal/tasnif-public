# Tasnif

Public website for Tasnif: https://tasnif.app/

Tasnif helps iPhone and iPad users understand what takes space in their Photos library while keeping photos and videos on device. It focuses on large videos, high-impact media, screenshots, RAW files and probable duplicates before the user decides what to review.
